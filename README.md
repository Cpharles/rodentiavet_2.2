# Landing Page - Rodentia Vet - v2.2
Landing-page de teste para a empresa Rodentia Vet, será feito um deploy na plataforma Versel

## Fluxo para atualização dos arquivos
1. Instalar dependências, se necessário
`npm install`  

2. Verificar TypeScript
`npx tsc --noEmit`

3. Testar aplicação
`npm run dev`

4. Gerar build
`npm run build`

5. Verificar arquivos do Git
`git status`

6. Adicionar arquivos
`git add .`

7. Conferir novamente
`git status`

8. Criar commit
`git commit -m "Initial commit"`

9. Configurar repositório remoto
`git remote add origin https://github.com/USUARIO/REPOSITORIO.git`

10. Enviar
`git branch -M main`
`git push -u origin main`
